## 📖 About

**StepCircle** is a simple step-tracking app that makes staying active more fun with family. Track your daily activity, join a family group, compete on the leaderboard, complete challenges, and celebrate achievements together.

> 🚀 **Live on Google Play:** [Download StepCircle](https://play.google.com/store/apps/details?id=com.samapplications.stepcircle)

---

## ✨ Features

| | Feature | Description |
|---|---|---|
| 🏃 | **Track Your Activity** | Daily steps, distance and active calories via Health Connect |
| 👨‍👩‍👧‍👦 | **Family Groups** | Create your own family or join one using an invite code |
| 🏆 | **Leaderboard** | Friendly competition with your family members |
| 🎯 | **Challenges** | Work towards walking goals together |
| 🏅 | **Achievements** | Unlock milestones as you keep moving |
| 🚫 | **Member Management** | Ban members from your family group |

## 🔒 Privacy

Your activity. Your privacy. StepCircle only uses your health and fitness data to provide its step-tracking and family features. Your health data is **never** used for advertising or sold to third parties.

📄 [Privacy Policy](https://stepcircle.netlify.app/privacy.html)

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-username>/stepcircle.git

# Go to the project folder
cd stepcircle

# Install dependencies
flutter pub get

# Run the app
flutter run
```

> **Requirements:** Flutter SDK, Android Studio / VS Code, and an Android device or emulator with Health Connect support.
